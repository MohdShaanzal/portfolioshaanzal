SHAANZAL PORTFOLIO WEBSITE

Files:
- index.html: website structure and content
- style.css: layout, colors, responsive design
- script.js: mobile navigation and active menu behavior
- assets/profile.jpg: your portrait

HOW TO RUN:
1. Extract the ZIP.
2. Open the shaanzal_portfolio folder.
3. Double-click index.html to open it in a browser.

HOW TO CUSTOMIZE:
- Edit index.html to change text, projects, email, or social links.
- Edit style.css to change colors and layout.
- Replace assets/profile.jpg to use another portrait (keep the same filename).
- Update the placeholder email your.email@example.com in index.html before publishing.
- Replace GitHub and LinkedIn links with your actual profile links.

GITHUB PAGES:
Upload all files and folders while preserving this structure. Keep index.html at the repository root.
